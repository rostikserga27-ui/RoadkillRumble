# Roadkill Rumble — прототип

Физическая кооп-игра от первого лица. Дизайн-документ: https://claude.ai/code/artifact/6c2a188d-939e-44e1-ad09-7c556c1af5ac

## Для участников: как развернуть проект

1. Установите [Git](https://git-scm.com/download/win), [Unity Hub](https://unity.com/download) и в нём **Unity 6000.6.4f1** (та же версия, что у всех, иначе Unity будет переконвертировать проект).
2. Склонируйте репозиторий:
   ```
   git clone https://github.com/rostikserga27-ui/RoadkillRumble.git
   ```
3. Unity Hub → **Add → Add project from disk** → папка `RoadkillRumble`. Первое открытие займёт несколько минут: Unity скачает пакеты (Netcode, Steamworks.NET, MCP for Unity).
4. Откройте сцену `Assets/Scenes/Greybox.unity` и нажмите **Play**.
5. Blender нужен только для правки персонажа: исходник `ArtSource/Fisherman/` (`SK_Fisherman.blend` и рецепт `fisherman_recipe.py`, который собирает модель с нуля), экспорт в `Assets/_Roadkill/Art/Fisherman/`. После нового экспорта жмите **Roadkill → Rebuild Network Prefabs**.

**Как работать вместе, чтобы не ломать друг другу проект:**

- Перед работой: `git pull`. После: `git add -A`, `git commit -m "что сделал"`, `git push`.
- Делайте свою задачу в отдельной ветке (`git switch -c имя-задачи`) и вливайте через Pull Request на GitHub.
- Не редактируйте вдвоём одну сцену или префаб одновременно: Unity-файлы плохо сливаются.
- Префабы в `Resources/RoadkillNet` руками не правьте: их генерирует `NetPrefabBuilder.cs`. Меняйте код и жмите **Roadkill → Rebuild Network Prefabs**.
- Чтобы играть друг с другом, у всех должна быть сборка с одного и того же коммита: при разных префабах Netcode не соединит.

## Как запустить

1. Откройте проект в Unity 6 (6000.6.4f1) через Unity Hub.
2. Откройте сцену `Assets/Scenes/Greybox.unity` и нажмите **Play**.
3. В окне лобби нажмите **Host**: вы хост и первый игрок.

Сетевые префабы (игрок и предметы) лежат в `Assets/_Roadkill/Resources/RoadkillNet`. Они собираются сами при открытии проекта, а вручную — через меню **Roadkill → Rebuild Network Prefabs**. Пересобирайте их после правок в `PropLibrary.cs` или в сборке игрока.

## Мультиплеер

**Через Steam (основной способ).** Steam должен быть запущен. Хост нажимает **Host via Steam**, а в игре жмёт **F4** и приглашает друзей. Друг принимает приглашение или в списке друзей выбирает «Присоединиться к игре». IP и порты не нужны: трафик идёт через ретрансляторы Steam. Пока у игры нет своей страницы, используется тестовый App ID 480 (Spacewar), он лежит в `steam_appid.txt`.

**Отправить другу:** меню **Roadkill → Build For Friend (zip)**. Оно соберёт релиз и положит `steam_appid.txt` и `ЧИТАЙ_МЕНЯ.txt` в `Builds/RoadkillRumble.zip`.

**Через IP** есть три способа.

- **В одном редакторе.** Window → Multiplayer → Multiplayer Play Mode, включите Player 2. В его окне нажмите **Join** (адрес 127.0.0.1).
- **Сборкой.** File → Build Profiles → Windows → Build, в папку `Builds/Win`. Запустите exe и нажмите **Join**.
- **По локальной сети.** Хост нажимает **Host**, друг вводит IP хоста и порт 7777 и жмёт **Join**. Порт 7777/UDP должен быть открыт в брандмауэре.

Ключи командной строки: `-rkhost`, `-rkjoin 192.168.0.10`, `-rktest`. Последний запускает автотест: клиент сам встаёт к ящику на 75 кг, хватает его и пишет результат в лог. `-rktestfly`: клиент подбрасывает себя рэгдоллом, лежит, встаёт и приседает, записывая позу костей в лог — сравните с тем, что видит хост.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / Shift / Ctrl / Space | ходьба / бег / присед / прыжок |
| ЛКМ / ПКМ (держать) | схватить левой / правой рукой |
| G (держать, отпустить) | бросить то, что в руках |
| F (нажать / держать) | удар кулаком: джеб / заряженный хук; кулаки чередуются |
| C (держать) | прикинуться опоссумом |
| Space, когда лежишь | встать быстрее |
| F2 / V | переключить открытый микрофон или рацию / говорить в режиме рации |
| F3 | слышать себя (проверка микрофона) |
| F4 | пригласить друзей через Steam (у хоста) |
| F9 | правила площадки (для всех игроков) |
| R / F1 / Esc | респаун / подсказка / освободить мышь |

При удержании **C** тело рыбака обмякает (активный рэгдолл): руки, ноги, голова и туловище сталкиваются с миром по отдельности.
Так же падаешь от удара предметом и с высоты.
При любом падении камера плавно отъезжает за персонажа, чтобы было видно падение.
После отпускания C она остаётся снаружи до завершения вставания и плавно возвращается
к виду от первого лица. Во время перехода руки от первого лица скрыты, захват предметов
временно отключён. Камера сохраняет ровный горизонт и учитывает препятствия.
Клавиша **R** сразу сбрасывает камеру вместе с персонажем.

Проверка камеры в Unity: запустите Greybox → Host, удерживайте C на открытом месте,
отпустите и дождитесь вставания. Повторите у стены, при коротком нажатии C,
при повторном нажатии во время возврата камеры и с R во время падения.
На втором клиенте проверьте, что камера переключается только у нажавшего C игрока.

Голос слышно на 25 м, за стеной он глуше. Играйте в наушниках: на одном компьютере микрофон ловит звук из колонок.

## Площадка (Greybox)

Тестовый уровень — площадка, чтобы с друзьями пробовать способности и рэгдолл. Всё строится кодом (`GreyboxBuilder`); стороны света — от точки появления (вы смотрите на север).

- **Площадь (спавн):** ряд предметов для проверки веса (гном 3 кг … двигатель 180 кг; одна рука держит 20 кг, один игрок — 40 кг, двое — 80 кг), пирамида коробок и раздатчик коробок, гномы на столбах — сбивайте бросками. Две кнопки на земле: **RESET PROPS** (все предметы на место) и **EVERYBODY FLOP!** (все падают).
- **Север:** две **рэгдолл-пушки** — встаньте на красный круг, через секунду вас выстрелит обмякшим телом по дуге: одна пушка в стену из коробок, другая в бассейн с шариками. Ящики на круге тоже улетают. Рядом **вентилятор**: заходите в поток и парите (вокруг поролон).
- **Восток:** три **батута** (обычный, большой, супер; держите Space при приземлении — прыгнете выше). Супер-батут подбрасывает на 15 м — жмите W, чтобы приземлиться на **небесную платформу** 12 м. С неё — прыжок веры в поролон на запад, бетон в любой другой стороне (рэгдолл и урон) или **ледяная горка** на восток. Там же башни 4,5 м (рэгдолл без урона) и 8 м (рэгдолл и 20 урона).
- **Запад:** **бревно-мост** (проверка этапа 0: вдвоём перенести ящик 75 кг), **мост с молотами** над поролоном, **вертушка** — арена с вращающимися балками: нижнюю перепрыгивайте, под верхней приседайте (Ctrl); кто остался на ногах — победил.
- **Юго-запад:** **качающееся бревно** 60 кг (сбивает, решает сервер), **карусель** — разгоняется и сбрасывает (на большой скорости вы кувыркаетесь), **каток**: шины-шайбы и ворота.
- **Юг (за спиной):** площадка для **вышибал** — красные мячи 3 кг из раздатчиков; хороший бросок сбивает с ног.

**Правила площадки (F9)** включает любой игрок, действуют они для всех: лунная гравитация, суперпрыжок, турбо-бег, сильные руки (поднять ×4, бросок ×1,8), «стеклянная челюсть» (сбивает любой удар и падение с 1,6 м), «желейные ноги» (шатающиеся тела), ледяной мир, без урона. Там же кнопки: сбросить предметы, все падают, собрать всех у себя. Кто что включил, видно в ленте сверху.

Как это работает по сети: вращающиеся и качающиеся препятствия движутся по общим часам (`PlaygroundClock`, от серверного времени), поэтому одинаковы у всех без передачи данных. Сбивает и подбрасывает игрока его собственная машина (как и при падениях), предметы — сервер. Правила хранит сетевой объект `PlaygroundRules`. Шарики в бассейне у каждого свои (декорация).

## Кулаки

Удар — настоящее движение руки рэгдолла, а попадание — настоящее столкновение кулака (без анимаций и хитбоксов).

- **F нажать** — быстрый джеб (около 10 урона), **F держать** — замах и мощный хук (до 35 урона, в голову ×1,5). Кулаки чередуются; рука, которая что-то держит, не бьёт.
- **Фазы:** замах (кулак к подбородку, плечо назад), удар, возврат. Кулак летит в точку под прицелом со скоростью 9–14 м/с, корпус доворачивается и подаётся вперёд. Хук сначала делает шаг и поворачивает бёдра, потом бросает руку, иначе короткая рука рыбака не достаёт до лица соседа.
- **Выносливость:** полоска FISTS над RPM. Джеб стоит 12, хук до 32, восстановление 22 в секунду. Без сил удар не начинается.
- **Попадание:** считается, только пока удар «живой» и скорость кулака по нормали контакта не меньше 3,5 м/с; касания не в счёт. Урон и отбрасывание растут со скоростью кулака и массой руки (заряд добавляет вес тела). Импульс прикладывается к той кости, в которую попали, поэтому голова, корпус и нога отлетают по-разному. Слабый удар — пошатывание (суставы ненадолго мягче), сильный — нокдаун в рэгдолл.
- **Предметы** тоже можно бить: сервер толкает их в точке удара. Тяжёлый предмет, отлетевший быстрее 3 м/с, сбивает людей как обычно.
- **Огонь по своим** всегда включён физически (кулак сталкивается с любым телом). Хост выбирает правила: галочка в лобби и панель «FISTS» рядом с F9. Урон по своим 50%, отбрасывание 100%. Защита от гриферства (отключаемая): 3 с неуязвимости после появления и не больше 50 урона от одного товарища за 30 с. Попадание по другу — розовые искры и «OOPS!».
- **Ощущение удара:** стоп-кадр кулака, тряска и рывок камеры у бьющего и у получившего, искры, всплывающие «BONK!» / «POW!», звуки-заглушки (свист, удар, «боинг» при очень сильном ударе).
- **Настройка:** все числа в `Assets/_Roadkill/Resources/Combat/PunchConfig.asset` (откройте в инспекторе). Свои звуки можно перетащить в поля Sound.
- **Автотест:** хост с ключом `-rktestpunch` (или компонент `PunchAutotest` в Play Mode) бьёт коробки, а если подключён второй игрок, то бьёт и его. Пишет в лог `RK-PUNCH ... PASS/FAIL`. Клиент с `-rktestpunchvictim` стоит на месте и пишет своё здоровье и падения. Проверено хост + клиент: джеб в грудь 8–10 урона (по своим 4–5), хук в голову около 30 (по своим 15–16) и нокдаун, огонь по своим выключается, тела стабильны.

## Персонаж и активный рэгдолл

- **Модель:** low-poly рыбак (майка, шорты, шлёпанцы), 2440 треугольников, одна палитра, риг Humanoid. Цвет майки — цвет игрока.
- **Тело — активный рэгдолл** (`ActiveRagdollController`): каждая кость — Rigidbody на ConfigurableJoint, «анимация» — цели суставов (походка вразвалку, мах руками, болтание в воздухе, лёгкое покачивание), без анимационных клипов. Бёдра тянутся к капсуле игрока, торс держится над бёдрами, ступни ставятся под тело. Походка идёт по направлению движения: вбок — приставным шагом, назад — пятясь.
- **Руки:** схваченный предмет — руки тянутся к нему (если он дальше вытянутой руки, рыбак наклоняется к нему). Бросок: пока держишь G, рыбак откидывается назад и заносит руки, на отпускании — бросок вперёд. Заряд и момент броска передаются по сети, так что бросок видят все. Руки от первого лица тоже: отводятся назад при заряде и толкают вперёд при броске.
- **Геймплей не изменился:** движение, сеть, руки и удары по-прежнему на капсуле (`PlayerMotor`). Тело — косметика, капсулу оно не толкает. Своё тело владелец не видит (у него оно выключено), остальные видят рэгдолл; когда игрок падает в рэгдолл, тело обмякает.
- **Сборка:** `FishermanRagdollBuilder.cs` строит `Generated/Fisherman_Ragdoll.prefab` (коллайдеры подгоняются под меш), `NetPrefabBuilder` вкладывает его в `NetPlayer`.

**Тест рэгдолла:** откройте `Assets/Scenes/RagdollTest.unity` и нажмите Play (сеть не нужна). Там рампа с обрывом, крутой склон, ящики, батут, ящичная пушка и второй рыбак, который показывает, как вас видят другие игроки. ЛКМ / ПКМ — схватить ящик левой / правой рукой, G (держать и отпустить) — бросок, F5 — рэгдолл вкл/выкл, F6 — запустить в полёт, F7 — сброс, F8 — выстрел ящиком, V — вид от первого лица. Второй рыбак носит и бросает коробку — так это выглядит у других игроков. Панель слева: ползунки силы баланса, пружин суставов, болтливости головы и т. д.; **Run Autotest** прогоняет все сценарии и пишет `RK-RAGDOLL ... PASS/FAIL` в консоль.

## Как устроена сеть

- **Игрок:** двигается у себя (NetworkTransform в режиме Owner). Для остальных это кинематическая копия с головой, которая повторяет взгляд.
- **Предметы:** физику считает только хост. У клиентов они кинематические копии.
- **Руки:** клиент отправляет «схватить / отпустить / бросить» и позицию взгляда. Сервер держит невидимые якоря рук и тянет предмет пружиной с ограниченной силой, поэтому вес складывается честно.
- **Удары предметами:** засчитывает сервер (`ImpactReporter`) и сообщает пострадавшему.
- **Удары кулаком:** владелец сразу бьёт своей копией тела и сообщает серверу. Сервер проверяет удар (перерыв, выносливость, заряд не больше реального времени замаха) и показывает его остальным. Попадание засчитывается по столкновению кулака на машине бьющего («что видишь, в то и попал»). Бьющий сразу чувствует удар (стоп-кадр, камера, искры), а сервер проверяет заявку: удар его и ещё живой, каждая цель один раз, скорость правдоподобна, точка контакта рядом с обоими. Потом сервер считает урон и правила огня по своим, отправляет пострадавшему его реакцию и рассылает всем импульс по кости и эффекты.
- **Упавший игрок:** пока тело лежит или летит, владелец 15 раз в секунду рассылает позу всех костей (`RagdollPoseSync`, ~250 байт, ненадёжно). У остальных тело становится «марионеткой» и повторяет эту позу с задержкой 0,12 с, поэтому все видят его одинаково. Присед тоже передаётся.
- **Падение в рэгдолле:** пока игрок лежит, приземление считает тело (капсула в это время призрак), так что упасть с высоты в опоссуме (C) или после удара — тот же урон, что и на ногах.
- **Голос:** микрофон 16 кГц, сжатие μ-law, ненадёжная доставка через Netcode, 3D AudioSource на голове говорящего.
