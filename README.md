# Roadkill Rumble — прототип

Физическая кооп-игра от первого лица. Дизайн-документ: https://claude.ai/code/artifact/6c2a188d-939e-44e1-ad09-7c556c1af5ac

## Для участников: как развернуть проект

1. Установите [Git](https://git-scm.com/download/win), [Unity Hub](https://unity.com/download) и в нём **Unity 6000.6.4f1** (та же версия, что у всех, иначе Unity будет переконвертировать проект).
2. Склонируйте репозиторий:
   ```
   git clone https://github.com/rostikserga27-ui/RoadkillRumble.git
   ```
3. Unity Hub → **Add → Add project from disk** → папка `RoadkillRumble`. Первое открытие займёт несколько минут: Unity скачает пакеты (Netcode, Steamworks.NET, MCP for Unity).
4. Откройте сцену `Assets/Scenes/Greybox.unity` и нажмите **Play**.
5. Blender нужен только для правки персонажа: исходник `ArtSource/Character.blend`, экспорт в `Assets/_Roadkill/Art/Character/`.

**Как работать вместе, чтобы не ломать друг другу проект:**

- Перед работой: `git pull`. После: `git add -A`, `git commit -m "что сделал"`, `git push`.
- Делайте свою задачу в отдельной ветке (`git switch -c имя-задачи`) и вливайте через Pull Request на GitHub.
- Не редактируйте вдвоём одну сцену или префаб одновременно: Unity-файлы плохо сливаются.
- Префабы в `Resources/RoadkillNet` руками не правьте: их генерирует `NetPrefabBuilder.cs`. Меняйте код и жмите **Roadkill → Rebuild Network Prefabs**.
- Чтобы играть друг с другом, у всех должна быть сборка с одного и того же коммита: при разных префабах Netcode не соединит.

## Как запустить

1. Откройте проект в Unity 6 (6000.6.4f1) через Unity Hub.
2. Откройте сцену `Assets/Scenes/Greybox.unity` и нажмите **Play**.
3. В окне лобби нажмите **Host**: вы хост и первый игрок.

Сетевые префабы (игрок и предметы) лежат в `Assets/_Roadkill/Resources/RoadkillNet`. Они собираются сами при открытии проекта, а вручную — через меню **Roadkill → Rebuild Network Prefabs**. Пересобирайте их после правок в `PropLibrary.cs` или в сборке игрока.

## Мультиплеер

**Через Steam (основной способ).** Steam должен быть запущен. Хост нажимает **Host via Steam**, а в игре жмёт **F4** и приглашает друзей. Друг принимает приглашение или в списке друзей выбирает «Присоединиться к игре». IP и порты не нужны: трафик идёт через ретрансляторы Steam. Пока у игры нет своей страницы, используется тестовый App ID 480 (Spacewar), он лежит в `steam_appid.txt`.

**Отправить другу:** меню **Roadkill → Build For Friend (zip)**. Оно соберёт релиз и положит `steam_appid.txt` и `ЧИТАЙ_МЕНЯ.txt` в `Builds/RoadkillRumble.zip`.

**Через IP** есть три способа.

- **В одном редакторе.** Window → Multiplayer → Multiplayer Play Mode, включите Player 2. В его окне нажмите **Join** (адрес 127.0.0.1).
- **Сборкой.** File → Build Profiles → Windows → Build, в папку `Builds/Win`. Запустите exe и нажмите **Join**.
- **По локальной сети.** Хост нажимает **Host**, друг вводит IP хоста и порт 7777 и жмёт **Join**. Порт 7777/UDP должен быть открыт в брандмауэре.

Ключи командной строки: `-rkhost`, `-rkjoin 192.168.0.10`, `-rktest`. Последний запускает автотест: клиент сам встаёт к ящику на 75 кг, хватает его и пишет результат в лог.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / Shift / Ctrl / Space | ходьба / бег / присед / прыжок |
| ЛКМ / ПКМ (держать) | схватить левой / правой рукой |
| G (держать, отпустить) | бросить то, что в руках |
| C (держать) | прикинуться опоссумом |
| Space, когда лежишь | встать быстрее |
| F2 / V | переключить открытый микрофон или рацию / говорить в режиме рации |
| F3 | слышать себя (проверка микрофона) |
| F4 | пригласить друзей через Steam (у хоста) |
| R / F1 / Esc | респаун / подсказка / освободить мышь |

При удержании **C** тело падает рэгдоллом на костях: руки, ноги, голова и туловище сталкиваются с миром по отдельности.
Так же падаешь от удара предметом и с высоты, тогда камера смотрит из головы.
Камера при **C** плавно отъезжает за персонажа, чтобы было видно падение.
После отпускания C она остаётся снаружи до завершения вставания и плавно возвращается
к виду от первого лица. Во время перехода руки от первого лица скрыты, захват предметов
временно отключён. Камера сохраняет ровный горизонт и учитывает препятствия.
Клавиша **R** сразу сбрасывает камеру вместе с персонажем.

Проверка камеры в Unity: запустите Greybox → Host, удерживайте C на открытом месте,
отпустите и дождитесь вставания. Повторите у стены, при коротком нажатии C,
при повторном нажатии во время возврата камеры и с R во время падения.
На втором клиенте проверьте, что камера переключается только у нажавшего C игрока.

Голос слышно на 25 м, за стеной он глуше. Играйте в наушниках: на одном компьютере микрофон ловит звук из колонок.

## Что проверять на тестовом уровне

- **Ряд предметов** (впереди): гном 3 кг, шины 12 кг, аккумулятор 30 кг, бак 50 кг, диван 60 кг, коробка передач 75 кг, двигатель 180 кг.
  Одна рука держит 20 кг, один игрок — 40 кг, двое — 80 кг. Всё тяжелее можно только волочь.
- **Башни** справа: с 4,5 м падаешь в рэгдолл без урона, с 8 м получаешь рэгдолл и 20 урона.
- **Бревно-мост** слева: проверка этапа 0. Вдвоём перенесите ящик 75 кг по бревну.
- **Качающееся бревно** 60 кг сзади слева: встаньте у него на пути, и вас собьёт (это решает сервер).
- **Пирамида коробок**: тренировка бросков.

## Как устроена сеть

- **Игрок:** двигается у себя (NetworkTransform в режиме Owner). Для остальных это кинематическая копия с головой, которая повторяет взгляд.
- **Предметы:** физику считает только хост. У клиентов они кинематические копии.
- **Руки:** клиент отправляет «схватить / отпустить / бросить» и позицию взгляда. Сервер держит невидимые якоря рук и тянет предмет пружиной с ограниченной силой, поэтому вес складывается честно.
- **Удары предметами:** засчитывает сервер (`ImpactReporter`) и сообщает пострадавшему.
- **Голос:** микрофон 16 кГц, сжатие μ-law, ненадёжная доставка через Netcode, 3D AudioSource на голове говорящего.

```
  Scripts/Core     ввод, материалы, автозапуск тестового уровня

  Editor           меню Roadkill, сборка сетевых префабов
  Resources/RoadkillNet   сгенерированные сетевые префабы
```
